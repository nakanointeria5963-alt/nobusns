# はじめてのSNS

公開ページ: https://nakanointeria5963-alt.github.io/nobusns/

スマホやパソコンにあまり慣れていない人のための、SNSの手引きです。
**えらんで押していくだけ**で、始め方と使い方にたどり着けます。文字を打つのは、探したいときだけ。

## のっているもの

- **どれを使えばいいか、わからない** — やりたいこと(連絡したい・動画を見たい 等)を押すと、合うSNSと理由を出します
- **SNS別の手引き(6つ)** — LINE / YouTube / インスタグラム / フェイスブック / X(旧ツイッター) / TikTok
  - これは何をするところか(ひとことで)
  - はじめ方(番号つきの手順。1歩ずつ)
  - よくやること(写真を送る、電話をかける…押すと手順が開く)
  - 知ってると便利 / 気をつけること / よくある質問
- **こまったとき** — まちがえて送った、変な連絡が来た、「当選しました」が来た、など10件
- **ことばの意味** — アカウント、フォロー、既読…21語を、ふだんのことばで
- **文字の大きさ** — 右上の「あ」で3段階。選んだ大きさは覚えます

## つくりの考え方

- **表は簡単、奥に詳しく。** 最初に見えるのは大きなボタンだけ。詳しい説明は、押した人にだけ開く
- **手順は「1歩=1行動」。** ボタンの正確な位置ではなく、名前と流れで書く(アプリの画面はよく変わるため)
- **こわがらせない。** 詐欺の注意は「押さない・返事しない・消す」のように、やることだけを短く

## つくり

`index.html` の1枚だけ。サーバーも登録も外部への通信もありません。

- 中身の文章は、`<script>` の中の `SNS`(6つの手引き)・`GOALS`(おすすめ)・`KOMATTA`(こまったとき)・`KOTOBA`(ことば)にまとまっています。ここを書き換えれば、そのまま画面に出ます
- 画面の行き来は `#/sns:line` のような印でやっているので、**スマホの「もどる」ボタンが効きます**

## 公開のしくみ

`main` に変更が入ると、自動で GitHub Pages に反映されます(`.github/workflows/pages.yml`)。
